Privacy Policy

Last updated: 2026-11-05

Who uses this app

Agent is a personal tool used only by the owner of the connected Google account. It is not offered to other users.

Data accessed

With the owner's consent, the app accesses Google Drive, Google Docs, Google Sheets and Google Slides data of the owner's account, plus the basic profile and email address used to identify the account.

How data is used

Data is accessed only to perform actions the owner requests, such as reading, creating or editing the owner's own files. Data is not used for advertising, profiling or any purpose other than the requested action.

Storage

OAuth tokens are stored locally on the owner's computer. The app does not operate a server that collects or stores Google user data.

Sharing

Google user data is not sold, transferred or shared with third parties.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy: open an issue on GitHub.
